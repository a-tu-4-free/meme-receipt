## 這是什麼？

一個以台灣民眾黨政治事件為題材的**純前端嘲諷收據生成器**。

按一個按鈕，系統自動產生一張「政治獻金收據」，內容包含隨機高層代表、金流金額、嘲諷語錄，以及系統評語。

**沒有後端。沒有資料庫。沒有追蹤。只有梗。**

---

## 玩法說明

| 按鈕 | 功能 |
|------|------|
| 🎲 隨機撈錢 | 切換為隨機模式並生成收據，金額較低 |
| ☀ 堂口模式 | 切換為堂口模式並生成收據，金額更高、混亂值暴漲 |
| 🌞 雙太陽 | 開啟後收據會同時出現【咆哮戰神】與【白賊阿北】專屬語錄 |
| 💰 錢再多一點 | 升級（Lv.1–10），等級越高金額越大、彩蛋越多 |
| 📖 角色圖鑑 | 查看你已解鎖的堂口角色（共 70 位） |
| 📦 留下證據 | 下載截圖 |

### 收據互動
- **✏️ 編輯**：點擊後可直接修改收據內文，再截圖分享
- **🔄 再抽一張**：不滿意？馬上重抽
- **📤 分享**：一鍵分享到 FB、Twitter、Threads、LINE

### 隱藏系統
- **混亂值**：每次生成都會上升，突破 100 後有機率觸發 Glitch 語句
- **穩定度**：混亂值越高，穩定度越低——特偵組突襲機率同步上升
- **成就系統**：完成特定行為解鎖成就徽章（點「▼ 成就」展開查看）
- **今日任務**：每個 Session 隨機指派一個任務，完成解鎖成就
- **角色圖鑑**：70 位堂口角色，每次收據隨機解鎖，點擊查看專屬語錄
- **今日撈錢排行榜**：記錄你本次最高單筆金額（localStorage）
- **特偵組突襲**：隨時可能觸發，全螢幕蓋住畫面 3 秒

## 功能特色

- ✅ 純前端，無後端依賴
- ✅ 完整角色圖鑑系統（localStorage 持久化）
- ✅ 社群分享：FB / Twitter / Threads / LINE / Instagram / ibon 引導
- ✅ 收據可手動編輯後截圖
- ✅ 桌機單頁不捲動設計，手機自動適配
- ✅ 成就系統 + 連擊系統 + 升級系統
- ✅ 混亂值 / 穩定度動態機制
- ✅ 隱藏彩蛋（整點、整千、第10次等）

## 技術架構

```
meme-receipt/
├── index.html        # 主頁面、UI、Modal、社群分享邏輯
├── script.js         # 遊戲核心引擎（ES Module）
├── generator.js      # 金額、ID、時間、角色名生成器
├── ui.js             # 收據動畫、Glitch 特效、評語渲染
├── style.css         # 全站樣式
├── memes.json        # 所有梗文字資料庫
└── characters.json   # 70 位角色資料（emoji + 專屬語錄）
```

**使用的外部資源：**
- [html2canvas](https://html2canvas.hertzen.com/)（截圖功能）

## 想貢獻梗？

歡迎開 **Issue** 或 **Pull Request**，可以貢獻：

- `memes.json` 的任何區塊（openings / usages / glitch / system_weird 等）
- `characters.json` 新增角色或修改語錄
- 新功能建議

**貢獻原則：**
1. 內容需與民眾黨相關政治事件有關
2. 不接受針對個人人身攻擊的內容（政治行為可以嘲諷，個人外貌等請迴避）
3. 保持荒誕幽默的風格，不要真的氣到失控
